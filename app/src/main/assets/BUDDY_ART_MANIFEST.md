# Buddy Art Manifest

14 unique Learning Buddy characters x 6 poses = 84 assets.
Format: WebP, 512x512px, in `app/src/main/res/drawable-nodpi/`.
Art direction: soft modern flat-vector cartoon, rounded shapes, gentle gradients,
big expressive eyes, warm and friendly for ages 3-8. Poses generated from each
buddy's own idle image as reference for character consistency.

## Poses

| Pose | File suffix | Used for |
|------|-------------|----------|
| idle | `_idle` | Home FAB, chat headers, profile circles |
| happy | `_happy` | Correct answers, streaks, quest milestones |
| thinking | `_thinking` | Loading states, hints, warm-up |
| waving | `_waving` | Greeting hero card, first-run |
| comforting | `_comforting` | Wrong answers, breathing-buddy companion |
| celebrating | `_celebrating` | Mastery complete, shop purchase |
