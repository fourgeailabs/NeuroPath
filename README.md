## 🌟 Overview

**NeuroPath** is a comprehensive, sensory-conscious mobile learning application built with Kotlin and Jetpack Compose. Tailored specifically for children with ADHD, Autism, Dyslexia, Dyscalculia, and all curious learners, NeuroPath blends state-aligned academic curricula with personalized interest worlds, regulation tools, and assistive accessibility features.

By pairing core educational milestones with topics kids love (Mythical Creatures & Folklore, Space Odyssey, Dinosaurs, Deep Ocean, Superheroes, and Robotics), NeuroPath transforms learning into an engaging, low-anxiety quest.

## 🚀 Key Features

### 1. 🌊 Interactive Educational Game: Ocean Reading Quest
* **Deep Sea Fill-in-the-Blank (Cloze Comprehension)**:
  - Rich marine science passages (*The Vibrant Coral Reef Ecosystem*, *Midnight Abyss: Creatures of Bioluminescence*).
  - Scientific vocabulary word bank (*Coral, Ecosystem, Tentacles, Predator, Camouflage, Habitat, Bioluminescence, Trench, Plankton*).
  - Interactive tap-to-fill blanks, real-time Socratic hint coaching, and explanation cards.
* **Ocean Word Hunt (Touch Letter Grid)**:
  - 8x8 sensory bubble grid with letters.
  - Interactive word discovery tracking, glowing ocean highlights, instant haptic pops, and TTS pronunciation with fun facts.
  - Milestone celebrations awarding ⭐ Stars and 💎 Gems upon completion.

### 2. 🐉 New Theme: Mythical Creatures & Folklore
* **Lorekeeper Companion**: `Ignis the Drake` guides children through legendary tales, ancient wonders, and folklore mysteries.
* **Mythical Visual Tokens**: Deep mystic royal tones (`#581845`, `#C70039`, `#FFF5F8`).
* **Folklore Avatar Accessories & Pets**:
  - Avatars: *Solar Phoenix* 🦅, *Drake Knight* 🛡️, *Faerie Queen* 🧚‍♀️.
  - Hats & Accessories: *Mystic Dragon Horns* ✨, *Phoenix Feather Crown* 🪶.
  - Companion Pets: *Nine-Tailed Kitsune Fox* 🦊, *Mini Pegasus* 🦄.
  - Badges: *Folklore Lorekeeper Medal* 📜, *Deep Sea Explorer* 🪸.

### 3. 🎨 'Creative Expression' Studio Module
* **Art Studio (Freehand Drawing Canvas)**:
  - Smooth touch-driven canvas with customizable brush widths (Fine 4dp, Medium 12dp, Bold 24dp).
  - Sensory vibrant palette (Electric Cobalt, Ocean Teal, Dragon Flame, Forest Emerald, Magic Violet, Sun Gold).
  - **Themed Sticker & Stamp Drawer**: Stamp mythical creatures (🐉, 🦅, 🦄, 🧚‍♀️, 🏰), marine life (🐬, 🦈, 🐙, 🐠, 🪸), and cosmic wonders onto your drawings!
  - Undo, clear canvas, and artwork portfolio saving.
* **Story Writer (Themed Adventure Creator)**:
  - Themed adventure starters across Mythical, Ocean, Space, and Dino realms.
  - **✨ Spark Ideas with NeuroBuddy**: On-demand Gemini AI brainstorming to inspire imaginative narrative ideas.
  - Word counter, title editor, and built-in **Read Aloud TTS** playback.

### 4. 📚 State-Aligned Curriculum & Interest Worlds
* **US Educational Standards**: Built-in curriculum standards including Common Core State Standards (CCSS), Texas Essential Knowledge and Skills (TEKS), California Next Generation Science Standards (NGSS), New York Next Generation Standards, and Florida B.E.S.T.
* **Grade-Level Progression**: Kindergarten through 5th Grade coverage across Mathematics, English Language Arts (ELA), Science, Social Studies, and Social-Emotional Learning (SEL).
* **Hyper-Focus Theming**: Switch lesson skins seamlessly into any world:
  - 🐉 **Mythical Creatures & Folklore**
  - 🚀 **Space Odyssey**
  - 🦖 **Dino World**
  - 🌊 **Deep Ocean Discovery**
  - 🦸‍♀️ **Superhero Academy**
  - 🧙‍♂️ **Magic Realm**
  - 🎮 **Pixel Arcade**

### 5. 🫧 Sensory Regulation & Executive Function Tools
* **Interactive Fidget Pop-It**: Multi-texture sensory pop board with simulated bubble wrap, mechanical toggles, soothing haptic feedback, and audio chimes.
* **Guided 4-7-8 Breathing Circle**: Rhythmic animated diaphragm expander with audio pacing to de-escalate anxiety and reset focus.
* **Always-Accessible Sensory Bar**:
  - 🌓 **High Contrast Mode**: Crisp black/white high-visibility display.
  - 🌿 **Low Stimulation Mode**: Desaturated, minimal-motion environment.
  - 📖 **Dyslexia-Friendly Typography**: Weighted baseline font rendering for enhanced readability.
  - 🔊 **Quick Mute & Calming Ambient Audio**: One-touch sound management.

### 6. 🗣️ Synchronized TTS with Karaoke Word Highlighting
* Built-in Android Text-To-Speech engine with dynamic word-by-word highlighted playback.
* Adjustable speech rate and pitch settings to accommodate auditory processing differences.

### 7. 🤖 NeuroBuddy AI Companion
* Powered by Google Gemini API.
* An empathetic, growth-mindset tutor that breaks complex topics into bite-sized analogies, offers Socratic hints, and celebrates every learning step.

### 8. 🛍️ Gamification & Avatar Rewards Shop
* **Dual Economy**: Earn Stars ⭐ and Gems 💎 through lesson completion, reading games, creative expressions, and mindfulness breaks.
* **Avatar Customization**: Unlock and equip characters, cosmic gear, wizard hats, companion pets (Dragons, Kitsune, Pegasus, Galaxy Puppies, Owls), and achievement badges.

### 9. 🔒 Parent & Educator Dashboard
* **PIN Protected Gate**: Secure access control for parents and teachers.
* **Curriculum Customization**: Switch active state standards, grade levels, and learner profile tags (ADHD, Autism, Dyslexia, etc.).
* **Learning Analytics**: Track completed lessons, accuracy streaks, sensory tool usage, and mastery roadmaps.

## 🛠️ Architecture & Tech Stack

* **Language**: Kotlin 2.0+
* **UI Toolkit**: Jetpack Compose with Material Design 3 (M3)
* **Architecture**: Clean MVVM (Model-View-ViewModel) with StateFlow
* **Database & Persistence**: Room Database / Android Key-Value Data Layer
* **AI Integration**: Gemini API (Google Gen AI Client)
* **Speech Services**: Android TTS Engine with word boundary tracking
* **CI/CD**: GitHub Actions automated APK build workflow (`.github/workflows/build.yml`)

## 📦 Building and Running

### Prerequisites
* Android Studio Ladybug (2024.2.1+) or newer
* JDK 17 or JDK 21
* Android SDK 36 (targetSdk 36, minSdk 24)

### Local Build
```bash
# Clone the repository
git clone https://github.com/example/neuropath.git
cd neuropath

# Build Debug APK
./gradlew assembleDebug

# Output APK located at:
# app/build/outputs/apk/debug/app-debug.apk
```

### GitHub Actions CI
Every commit and pull request triggers an automated workflow in `.github/workflows/build.yml` that compiles the project and generates the downloadable debug APK artifact: `neuropath-v1.7.0-debug`.
